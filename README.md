# Week-5
This capstone report integrates the analytical work from the internship into one end-to-end data science project with two case studies. The first is an A/B test of a redesigned e-commerce checkout page, analysed with Welch t-tests, chi-square tests, ANOVA with Tukey post-hoc comparisons and a bootstrap analysis of revenue per session. It shows that the new design raises conversion from 11.6% to 16.5%, shortens checkout time and increases revenue per session without changing basket size. The second case study is a machine learning classifier for malignant versus benign tumours. Logistic regression, KNN, decision tree and random forest models were compared using cross-validation inside a leakage-safe pipeline, and logistic regression achieved about 96.5% accuracy and 0.996 ROC AUC. I extended this by choosing the decision threshold from cross-validated cost ratios, without using the test set. The report contains an executive summary, methodology, detailed results, 15 annotated visualisations, code excerpts and a synthesis of patterns across both studies. Strategic recommendations are grouped by stakeholder, with evidence, expected impact, effort and a 30-60-90 day roadmap, such as rolling out the new checkout, running a dedicated mobile test, targeting first-time buyers, and using the model only as clinical decision support after external validation. A section on business impact converts results into conservative, expected and optimistic scenarios. The report ends with limitations, such as simulated data, small samples and the lack of external validation, along with future improvements, a glossary and the complete code.
